Smart Parking
Management System
with AI

Intelligent parking occupancy estimation using computer vision.

Python · OpenCV · YOLO · Flask · SQLite

Why smart parking?

  • Drivers spend time searching for free spaces.
  • Manual observation can be slow and inconsistent.
  • Operators need timely occupancy information.

What the system aims to do

  • Detect vehicles in camera frames.
  • Map detections to parking regions.
  • Display occupied and available counts.
  • Store status history.

From camera frame to dashboard

Camera / Video → AI Detector → Occupancy Engine → SQLite DB → Flask UI

Tools & technologies

Python 3 · OpenCV · YOLO · Flask · SQLite · HTML/CSS/JS

Evaluation plan

  • Test occupied and empty bays.
  • Compare predictions with labelled ground truth.
  • Measure accuracy, false detections, FPS and dashboard delay.

Known constraints

  • Lighting, shadows and occlusion affect detection.
  • Fixed camera and calibrated regions are required.
  • Speed depends on hardware and model size.

Next improvements

  • Multiple-camera support.
  • Mobile dashboard and notifications.
  • Reservations and cloud reporting.
